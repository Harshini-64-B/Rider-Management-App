# Rider Management App
An interactive web prototype designed to demonstrate the user experience and booking flow of a ride-hailing application. Developed as part of the Human-Computer Interaction (HCI) coursework at IIITDM Kancheepuram.

## Live Demo
https://harshini-64-b.github.io/Rider-Management-App/

## Overview
The Rider Management App provides a mobile-style interface that allows users to explore a ride-booking experience, from account creation and destination selection to ride confirmation, payment and feedback.
The project focuses on designing intuitive user flows and creating an interactive interface that makes the ride-booking process simple and accessible.

## UI/UX Design
The interface was designed and refined using Figma before being implemented as an interactive web prototype.
[View Figma Designs](https://www.figma.com/design/6jeLbTBZPJZBJN2UVQmuH9/Design-Activity-Mid-Sem---CS23B1064?node-id=0-1&p=f&t=K31eAugvA32SUBNN-0)

## Features
- **Login and Sign Up:** User authentication interface designs.
- **Destination Selection:** Search for destinations and select locations using an interactive map.
- **Saved Places:** Quick access to frequently visited locations.
- **Ride Selection:** View available ride options, estimated arrival times and fares.
- **Booking Flow:** Interactive ride confirmation and driver assignment screens.
- **Driver Tracking:** Driver details, vehicle information and tracking interface.
- **Payment:** Payment method selection, including UPI and cash.
- **Ride History:** View previous rides and their status.
- **Ratings and Feedback:** Rate completed rides.
- **Help and Support:** Access support options and common assistance categories.
- **Scheduled Rides:** Interface for planning rides in advance.

- HTML5

## Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/Harshini-64-B/Rider-Management-App.git
   ```
2. Open the project folder.
3. Open `index.html` in a web browser.
An active internet connection is required to load the external map tiles and Leaflet resources.

## Note
This project is an academic front-end prototype created for demonstrating UI design, user flows and interactive ride-booking screens. It does not represent a production-ready ride-booking service with real payment processing, driver dispatch or backend authentication.
